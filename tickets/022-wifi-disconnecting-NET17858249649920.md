# NET17858249649920 – WiFi Keeps Disconnecting

**Priority:** Critical  
**Request Type:** Network / ISP Connectivity  
**User:** Diana Foster (`dfoster`)  
**Department:** HR  
**Date Completed:** September 21, 2026

## Summary
User reported that WiFi was disconnecting every few seconds. This caused multiple video call drops and prevented a stable connection for work.

## Steps Taken
1. Claimed the Critical ticket.
2. Opened Server Room → Devices.
3. Identified that the Metro ISP (external provider) was showing as down.
4. Selected “Check ISP Status” on the Metro ISP device.
5. Confirmed the ISP status returned to online.
6. Contacted the user, who confirmed the WiFi connection was now stable.
7. Added resolution notes and closed the ticket.

## Resolution
Root cause was an upstream Metro ISP outage.  
Running the ISP status check restored external connectivity, which resolved the frequent WiFi disconnections for the user.

## Skills Demonstrated
- Critical network incident response
- Use of Server Room monitoring tools
- Identifying upstream ISP vs local WiFi issues
- Clear communication with the affected user
