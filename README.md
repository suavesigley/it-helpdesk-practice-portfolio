# IT Helpdesk Practice Portfolio

Hands-on practice portfolio documenting real ticket resolutions, Active Directory tasks, and IT support workflows using ServiceDesk Simulator.

This repository showcases practical experience relevant to Tier 1 / Help Desk / Service Desk roles.

## Skills Demonstrated
- Active Directory / user account management
- Email and alias configuration
- Ticket handling and documentation
- Following change processes (e.g. HR-approved name changes)
- Basic troubleshooting workflow

## Repository Structure
- `tickets/` — Individual ticket case studies
- `active-directory/` — AD-focused examples
- `screenshots/` — Supporting evidence
- `PROGRESS.md` — Weekly progress log
