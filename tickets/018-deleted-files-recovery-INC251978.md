# INC251978 – Accidentally Deleted Important Files

**Priority:** High  
**Request Type:** Data Recovery  
**User:** Priya Sharma (`psharma`)  
**Department:** Engineering  
**Location:** Floor 3  
**Date Completed:** September 16, 2026

## Summary
User accidentally deleted a folder containing months of client proposals and contracts, then emptied the Recycle Bin. The deletion occurred approximately two hours prior to the ticket. This created an urgent need to recover critical business documents.

## Steps Taken
1. Claimed the high-priority ticket.
2. Initiated a remote support session to the user’s workstation.
3. Navigated to Cloud Drive → Version History → Recently Deleted Files.
4. Located the deleted folder `Client_Proposals_Project` (47 files) along with related documents.
5. Restored the Client_Proposals_Project folder and the additional files.
6. Confirmed the files were successfully recovered and accessible.
7. Added resolution notes and closed the ticket.

## Resolution
The deleted files were recoverable through Cloud Drive’s Version History / Recently Deleted Files feature (recoverable for 30 days).  
The full Client_Proposals_Project folder and related documents were successfully restored.

## Skills Demonstrated
- Data recovery using cloud version history
- Remote desktop support
- High-priority incident handling
- Clear communication under urgent data-loss conditions
