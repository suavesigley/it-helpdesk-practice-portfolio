# INC111932 – Outside Contractor Needs Temporary WiFi Access

**Priority:** Low  
**Request Type:** Account Creation / Temporary Access  
**Requested by:** Carlos Rodriguez (Building Manager)  
**Contractor:** Mike Torres – CoolAir Systems  
**Duration:** 2 days  
**Date Completed:** October 5, 2026

## Summary
Building Manager requested temporary WiFi access for an external HVAC contractor arriving the next day. The contractor only needed internet access (no internal resources) for diagnostic equipment. Approved username was `coolair_temp`.

## Steps Taken
1. Claimed the ticket.
2. Opened Tools → Directory.
3. Created a new user with the username `coolair_temp` (following the contractor naming convention of using the company name rather than the individual’s name).
4. Set the display name to Mike Torres.
5. Created the account.
6. Confirmed the account was ready for use.
7. Added resolution notes and closed the ticket.

## Resolution
Temporary contractor account `coolair_temp` was successfully created.  
Per policy the account is limited to internet-only access and should be removed after the 2-day engagement.

## Skills Demonstrated
- Following organizational naming conventions for contractor accounts
- Creating temporary / limited-access user accounts
- Handling facilities / vendor access requests
- Adhering to least-privilege principles (internet only)
