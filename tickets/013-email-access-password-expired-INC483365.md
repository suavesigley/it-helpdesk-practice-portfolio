# INC483365 – Cannot Access Email on Mobile / Any Device

**Priority:** Medium  
**Request Type:** Account Access / Password Reset  
**User:** Jessica Tran (`jtran`)  
**Department:** Engineering  
**Location:** Floor 3  
**Date Completed:** September 5, 2026

## Summary
User reported that work email was no longer syncing on her mobile device, showing “Cannot connect to server.” Further investigation revealed she was also unable to access email via laptop or webmail. Phone internet and other apps were working normally. This prevented her from receiving urgent messages while away from her desk.

## Steps Taken
1. Claimed the ticket.
2. Contacted the user and performed identity verification by sending a one-time code.
3. User returned the verification code via chat.
4. Reviewed the account and identified that the password had expired.
5. Performed a password reset and generated a temporary password.
6. Securely provided the temporary password to the user.
7. Confirmed the user could log in and access email again.
8. Added resolution notes and closed the ticket.

## Resolution
Root cause was an expired password.  
After identity verification, the password was reset and a temporary password issued. User regained full access to email across mobile, laptop, and webmail.

## Skills Demonstrated
- Secure identity verification before account changes
- Password expiration troubleshooting
- Multi-device email access support
- Clear communication during account recovery
