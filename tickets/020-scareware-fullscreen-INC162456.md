# INC162456 – Scareware Full-Screen Warning

**Priority:** High  
**Request Type:** Malware / Scareware Removal  
**User:** Michael Brown (`mbrown`)  
**Department:** Engineering  
**Location:** Floor 2  
**Date Completed:** September 21, 2026

## Summary
User’s screen was completely taken over by a full-screen red warning claiming the computer was infected. The page played a loud alarm, displayed a countdown timer, and urged the user to call a phone number immediately. The user had not called the number. This is a classic scareware / tech support scam tactic designed to pressure the victim.

## Steps Taken
1. Claimed the high-priority ticket.
2. Reassured the user not to call the number and confirmed it was a fake scareware page.
3. Initiated a remote support session to the workstation.
4. Moved the mouse to the top-left corner of the fake warning to reveal the close control and closed the page.
5. Opened Settings → Security and ran a Full scan.
6. Scan completed with no threats found.
7. Confirmed the desktop was fully usable again.
8. Added resolution notes and closed the ticket.

## Resolution
The incident was caused by a browser-based scareware page, not an actual malware infection.  
Closing the fake warning and running a full security scan confirmed the device was clean. No malicious software was installed.

## Skills Demonstrated
- Recognition and handling of scareware / tech support scams
- User education under pressure (preventing the user from calling the fake number)
- Remote desktop support
- Security scanning and verification
- High-priority incident response
