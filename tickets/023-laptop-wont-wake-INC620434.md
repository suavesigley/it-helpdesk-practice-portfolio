# INC620434 – Laptop Won’t Wake (Black Screen + Blinking Power Light)

**Priority:** Critical  
**Request Type:** Hardware / Power State Troubleshooting  
**User:** Nina Patel (`npatel`)  
**Department:** Engineering  
**Location:** Floor 3  
**Date Completed:** September 24, 2026

## Summary
User’s laptop would not wake from sleep. The screen remained completely black while the power light blinked slowly. Pressing the power button had no effect. The device was plugged in. This left the user completely unable to work ahead of an important meeting.

## Steps Taken
1. Claimed the Critical ticket.
2. Contacted the user and first suggested pressing the spacebar (common wake trigger) — this did not resolve the issue.
3. Instructed the user to fully disconnect the laptop from the dock, charger, and any external monitors.
4. Guided the user to perform a hard reset by holding the power button for approximately 30 seconds.
5. User pressed the power button again afterward — the laptop successfully powered on and woke up.
6. Confirmed with the user that the device was working normally.
7. Added resolution notes and closed the ticket.

## Resolution
The laptop was stuck in a failed sleep/hibernate power state.  
A full power drain (disconnect all power sources + hard reset) cleared the stuck state and allowed the laptop to boot normally.
