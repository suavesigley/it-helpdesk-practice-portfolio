# INC721417 – Customer Support Agent’s Laptop Dead (Remote)

**Priority:** Critical  
**Request Type:** Hardware Replacement (Laptop)  
**User:** Lisa Martinez (`lmartinez`)  
**Department:** Customer Support  
**Location:** Remote (Working from home)  
**Date Completed:** October 17, 2026

## Summary
Remote Customer Support agent’s work laptop would not power on at all (no lights, no fan, no response even after trying multiple chargers and a known-good outlet). This left the agent unable to sign into the softphone and take customer calls while working from home.

## Steps Taken
1. Claimed the Critical ticket.
2. Confirmed the device was a laptop and that it had a complete power failure.
3. Built a replacement laptop using Tools → Computer Deployment with Server Imaging (including baseline applications).
4. Registered the new asset and set it to “Ready to deploy”.
5. Checked the replacement out to the user via Asset Management.
6. Contacted the user via chat to obtain her home shipping address.
7. Shipped the laptop through Ship Manager and included a return label for the failed unit.
8. Confirmed the agent received the working laptop and could resume taking calls.
9. Added resolution notes and closed the ticket.

## Resolution
The original laptop had a complete power failure.  
A fully imaged replacement laptop was built, registered, checked out, and shipped to the user’s home address. Service was restored for the remote Support agent.

## Skills Demonstrated
- Critical hardware failure response for remote staff
- Differentiating laptop vs desktop replacement builds
- Computer Deployment / imaging process
- Asset registration and user checkout
- Coordinating shipping to a remote employee’s home address
- Restoring customer-facing support capacity under time pressure
